# Scientific Evidence Ledger v1

Status: `PRE-W7 / NON-OUTCOME PREPARATION`

This ledger is an evidence firewall. It does not authorize W7 inference and
does not promote readiness smoke, synthetic fixtures, or historical pilot
numbers into W7 evidence.

## Historical pilot

`HISTORICAL_PILOT` contains only references to the archived Week1–5 and A2
pilot record. Those artifacts are explicitly `NOT_W7_EVIDENCE` and
`NOT_CONFIRMATORY_EVIDENCE`. No historical metric is copied into a W7 result
field by this preparation branch.

## W6 readiness only

`READINESS_ONLY` contains model reproduction, strict loading, synthetic smoke,
distribution identity, license/provenance and adapter evidence. It contains no
scientific outcome. PartialEdit is the single currently ready external input;
PartialSpoof remains blocked by its two official identity mismatches.

## W7 formal pilot

`STATUS = NOT_STARTED` and `W7_SCIENTIFIC_INFERENCES = 0`.

All W7 metric values are `NOT_MEASURED`. Synthetic acceptance fixtures are
software tests only and are not evidence about W7 performance.

## Confirmatory

`STATUS = NOT_STARTED / NOT_AUTHORIZED`; `LEVEL2_OUTCOMES_ACCESSED = NO` and
`CONFIRMATORY_AUROC = NOT_MEASURED`. The confirmatory preregistration remains
an outcome-blind design artifact, not an execution record.

The machine-readable companion is
`SCIENTIFIC_EVIDENCE_LEDGER_V1.json`; its invariant checker rejects numeric
W7 or confirmatory values while the corresponding firewall state is closed.
